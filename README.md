Power Grid Dataset

Overview

This repository provides power grid datasets for academic research on power system analysis, optimization, and planning. The datasets are intended to support the development, validation, and comparison of computational methods for power systems.

Dataset Description

The repository contains power system test data, which may include network topology, bus information, transmission line parameters, generator configurations, and other relevant system parameters. These datasets can be used for power flow analysis, transmission network expansion planning, and related optimization studies.

Usage

The datasets are provided for academic and research purposes. Researchers may download the files and adapt them to their specific simulation environments. Please refer to the individual data files for detailed system parameters and configurations.
